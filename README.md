# 🌱 IrrigaTech

O **IrrigaTech** é um projeto acadêmico desenvolvido por nós, alunos da Fatec, que une tecnologia e sustentabilidade para promover a irrigação inteligente e o monitoramento do uso dos recursos hídricos nas plantações.

## 🎯 Objetivo do Projeto

Desenvolver uma interface que apresente soluções tecnológicas voltadas ao gerenciamento da irrigação agrícola, incentivando o uso consciente da água e contribuindo para uma agricultura mais sustentável.

O projeto foi pensado com foco na sustentabilidade e na conscientização sobre os problemas ambientais causados pelo consumo excessivo de água no planeta.

## 💧 Funcionalidades

O sistema conta com páginas dedicadas a:

- 🏠 **Página Inicial:** apresentação e visão geral do sistema.
- 🌾 **Áreas de Irrigação:** gerenciamento das áreas de plantio.
- ⚙️ **Programadores:** interface para controle dos programadores de irrigação.
- 📊 **Relatórios:** visualização de informações e dados.
- 📡 **Sensores:** acompanhamento dos sensores.
- 💬 **Feedback:** espaço para opiniões e sugestões.
- 🛠️ **Suporte:** informações e suporte ao usuário.

## 🌍 Sustentabilidade

O projeto está relacionado ao **ODS 6 – Água Potável e Saneamento**, da Organização das Nações Unidas (ONU), que busca assegurar a disponibilidade e a gestão sustentável da água.

## 🎓 Desenvolvimento Acadêmico

Projeto desenvolvido por alunos da **Faculdade de Tecnologia de Franca (Fatec)**, como parte das atividades acadêmicas do curso de Desenvolvimento de Software Multiplataforma.
